1. SCHWARZSCHILD RAY CLASS:
Create a sophisticated ray class that follows curved spacetime:
- Store position in polar coordinates (r, φ) for the Schwarzschild metric
- Maintain conserved quantities: energy E and angular momentum L
- Implement conversion between coordinate time derivatives and affine parameter λ
- Use the null geodesic condition to relate spatial and temporal components

Key physics concepts:
- Schwarzschild metric: ds² = -(1-rs/r)c²dt² + (1-rs/r)⁻¹dr² + r²dφ²
- Null geodesics: light follows paths where ds² = 0
- Conserved quantities from Killing vectors of the metric
- Affine parameter λ provides proper parameterization

2. CONSERVED QUANTITY CALCULATION:
From initial Cartesian velocity, compute:
- Decompose velocity into radial (vᵣ) and angular (ω = rdφ/dt) components
- Calculate metric factor f(r) = 1 - rs/r
- Solve null condition to find dt/dλ from coordinate velocities
- Compute energy: E = f(r) × dt/dλ
- Compute angular momentum: L = r² × dφ/dλ

3. GEODESIC EQUATIONS:
Implement the geodesic equation d²xᵘ/dλ² + Γᵘᵥₚ(dxᵥ/dλ)(dxᵖ/dλ) = 0
For Schwarzschild metric in (r,φ) coordinates:
- d²r/dλ² = -(rs/2r²)(1-rs/r)⁻¹(dt/dλ)² + rs(dr/dλ)²/2r²(1-rs/r) + (1-rs/r)(rdφ/dλ)²
- d²φ/dλ² = -2(dr/dλ)(dφ/dλ)/r

4. RK4 INTEGRATION:
Implement 4th-order Runge-Kutta for the geodesic system:
- State vector: [r, pᵣ, φ] where pᵣ = dr/dλ
- Derivatives: [pᵣ, d²r/dλ², dφ/dλ]
- Use conserved quantities to compute missing derivatives
- Integrate in affine parameter λ with small steps (try λ_step = 1e-6)
