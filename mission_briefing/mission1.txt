1. FRAGMENT SHADER IMPLEMENTATION:
You need to replace the placeholder fragment shader with logic that:
- Declares uniforms for black hole center, radius, and grid spacing
- Uses gl_FragCoord.xy to get current pixel position
- Calculates distance from pixel to black hole center
- Creates grid lines using modulo operations on pixel coordinates
- Blends background color with grid line color
- Renders black hole as a solid black disc when distance < radius

**Why provide vertex shader:** The coordinate transformation from screen pixels to OpenGL normalized coordinates is complex and not physics-related.
You should focus on implementing Einstein's physics, not graphics programming details. So it's already part of the skeleton branch and solution branch.

Key concepts for fragment shader:
- Use `length(frag - u_center)` to calculate distance to black hole
- Use `mod(frag.x, u_grid_gap) < 1.0` for grid line detection
- Use `mix(background_color, grid_color, grid_factor)` for blending
- Colors: Dark blue background (0.03, 0.04, 0.07), lighter grid (0.12, 0.14, 0.20)

2. INITIALIZE METHOD:
Complete the initialization by:
- Setting uniform values for center position, black hole radius, and grid spacing (~24.0)
- Creating a vertex array object (VAO) for background rendering
- The VAO should use the background program with no vertex buffer (full-screen triangle)

3. RENDER METHOD:
Implement rendering by:
- Calling the VAO's render method
- Use TRIANGLES mode with 3 vertices (creates full-screen triangle)
- This will execute your fragment shader for every pixel on screen
